# Mudhakir | مُدَّخِر

Mudhakir is a UX design project developed as part of a User Experience course at King Saud University.

The project focuses on designing a user-friendly mobile application that helps users manage and track their personal expenses and savings through an intuitive and accessible interface.

## Project Overview

Mudhakir was designed using a user-centered design approach. The project involved understanding user needs, identifying usability requirements, designing the application interface, and evaluating the proposed design.

The final outcome is an interactive mobile application prototype designed using Figma.

## UX Design Process

The project followed a user-centered design process that included:

- User research through interviews and surveys
- Persona development
- User journey mapping
- Storyboarding
- Information architecture
- Wireframing
- Interactive prototyping
- Usability testing and evaluation

## Key Features

- User registration and login
- Personal expense tracking
- Expense categorization
- Savings management
- Financial information visualization
- Simple and user-friendly navigation
- Interactive mobile interface
